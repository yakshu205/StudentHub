# Practical-8: Registration Form with MySQL Database

StudentHub Registration Form se jo bhi register kare uska data directly MySQL database me save hoga.

---

## 📁 Files:
- **`register.php`**: Original Registration Form jo data submit hone par MySQL me insert karta hai.
- **`db.php`**: Database connection (`localhost`, `root`, `studenthub_db`).
- **`register.css`**: Original StudentHub Registration styling.
- **`database.sql`**: Database and table structure.

---

## 🚀 Kaise Chalayein:
1. XAMPP me **Apache** aur **MySQL** start karein.
2. Browser me open karein:
   ```
   http://localhost/StudentHub/Practical-8/register.php
   ```
3. Form bharein aur **Register** par click karein.
4. **phpMyAdmin** me data check karein:
   - URL: `http://localhost/phpmyadmin`
   - Database: `studenthub_db`
   - Table: `students`
